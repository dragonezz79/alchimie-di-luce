# Alchimie di Luce

Sito React strutturato per GitHub e Netlify.

## Struttura

- `src/components/`: sezioni visive del sito.
- `src/data/`: testi, prezzi, link, contatti e immagini.
- `src/styles/global.css`: stile generale del sito.
- `netlify.toml`: impostazioni di deploy per Netlify.

## Avvio locale

```bash
npm install
npm run dev
```

## Build per Netlify

```bash
npm run build
```

Su Netlify usa:

- Build command: `npm run build`
- Publish directory: `dist`
